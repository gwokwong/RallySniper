# RallySniper（主升浪捕手）

> 仓库名 / 项目英文名：**RallySniper** —— 像狙击手一样等待"涨停回调后再放量启动"的那一刻出手。

基于 **Vue 3（Art Design Pro 模板）** + **Python FastAPI** + **AKShare** 的本地 A 股盯盘工具。

**核心目标**：抓主升浪的起爆点——重点识别"涨停后缩量回调、不破涨停日最低价、再放量启动"的买点；同时盯着已标记持有的股票，出现危险信号（破位/天量阴线）时及时提醒离场。通知方式：**站内通知 + 邮件**。

---

## 一、它是做什么的

你维护一个"标的池"（想盯的股票代码），系统定时用日K数据识别上涨战法形态；同时对全市场扫描涨停回调机会。命中开启的战法后，发通知告诉你：哪只票、什么阶段（观察中/放量启动）、命中理由、量比、换手率、主力资金。每只票还可在标的池里「标记持有」，进入持仓风控，出现破位类信号时盘中预警、尾盘确认。

- **买点（上涨）**：默认只开启「涨停回调」，其余战法保留可随时打开。
- **卖点（下跌/离场）**：默认只开启「双线死叉」与「生命线破位」两个危险信号。
- **去重**：同一股票同一信号在冷却期内不重复提醒；盘中预警与尾盘确认分开推送。

### 上涨战法

| 战法 | 判定条件（可量化） | 特点 | 默认 |
|---|---|---|---|
| **涨停回调**（核心） | 近 N 日涨停（含连板）→ 缩量回调守住涨停日最低价 → 再放量且站上10日线 | 低吸起爆点，两阶段提醒（观察中 / 放量启动） | 开启 |
| **量价突破** | 5/10/20/60 日均线多头且向上，放量≥1.5倍，突破20日高点 | 信号最直接，贴合"进入主升那一刻" | 关闭 |
| **三重共振** | 3个交易日内均线、量能、MACD 三者金叉/放大同步 | 多指标验证，误报少 | 关闭 |
| **四特征共振** | 近一月涨停 + 温和倍量 + 跳空缺口3日不补 + 连续3根阳线 | 信号少而精，难造假 | 关闭 |
| **龙出水** | 横盘≥40日（振幅≤35%）、均线粘合，放量≥2倍突破箱体 | 抓长期横盘后爆发 | 关闭 |
| **三线底部启动** | 60日线走平上拐 + 5穿20金叉 + 5>20>60多头 + 站稳60日线 | 抓底部反转，成本低 | 关闭 |

涨停回调支持按板块与价格筛选（ST / 主板 / 科创板 / 创业板 / 北交所、价格区间），默认排除 ST 与北交所。涨停阈值按板块自动区分（主板 9.8% / 科创创业 19.5% / 北交 29.5% / ST 4.8%）。阈值均可在界面调整。

### 下跌 / 离场战法（及时止盈止损）

| 战法 | 判定条件（可量化） | 特点 | 默认 |
|---|---|---|---|
| **双线死叉** | 5日线位于20日线下方（死叉状态），刚死叉或处于相对高位 | 最直观的离场信号 | 开启 |
| **生命线破位** | 收盘有效跌破20日线（斜率向下 + 1%缓冲 + 连续2日确认） | 防深套的保命底线 | 开启 |
| **三死叉见顶** | 均线死叉 + 均量死叉 + MACD死叉，3日内同步 | 多指标共振，高位准确 | 关闭 |
| **MACD高位死叉** | DIF在零轴上方下穿DEA，或顶背离 | 动能衰竭警示 | 关闭 |
| **量价背离** | 股价创近30日新高但成交量萎缩 | 头部先行指标 | 关闭 |

持仓卖出提醒只对「已标记持有」的股票生效，含两种信号：**天量破位**（量比≥5 且阴线跌破关键位）与 **20日线确认破位**。节奏为盘中每 5 分钟扫一次（仅交易时段），14:50 尾盘按收盘口径确认。研究结论：单独用 5/10 日线噪音大；20 日线需加斜率与缓冲确认；主力资金单日流出无跨期预测力，故不作单独触发。

### 页面

- **盯盘总览**：市场状态、上涨/下跌命中统计、友好/危险两区信号、立即扫描
- **标的池**：券商自选股式管理，K线/均线/日内分钟线、量比换手、**加入/取消持有标记**
- **全市场机会**：涨停回调再突破扫描结果，快捷「加入标的池」，14:00 / 14:40 自动站内+邮件推送；交易日扫当日，非交易日自动取最近一个交易日并标注日期
- **昨日涨停跟进**：按连板/炸板/跌停/高开低走等术语分类昨日涨停股今日表现，标注行业与市场板块，10:30 / 14:40 简报
- **持仓风控**：持有列表、卖出信号、阈值参数、盘中预警与尾盘确认状态
- **战法说明**：各战法的判定条件与使用建议
- **邮件与配置**：标的池、战法开关、阈值、全市场筛选范围、SMTP 邮件、定时推送、测试邮件

## 二、一键启动

### macOS / Linux
```bash
cd 项目目录
chmod +x start.sh
./start.sh
```

### Windows
双击 `start.bat`

首次启动会自动创建 Python 虚拟环境、安装后端与前端依赖（较慢），之后启动很快。

启动后访问：
- **前端界面**：http://localhost:3006
- **后端 API**：http://localhost:8000/api/health

按 `Ctrl+C`（mac/Linux）或关闭弹出的服务窗口（Windows）即可停止。

## 三、快速上手（3 步）

1. 打开「**邮件与配置**」页，填入 SMTP 服务器、账号、授权码、收件邮箱，打开"启用邮件提醒"，点"发送测试邮件"确认收到。
2. 把你想盯的股票代码加入"标的池"，在「全市场机会」页也可一键把筛选出的票加入。
3. 打开"自动盯盘"开关并保存。系统即常驻运行，命中战法自动发通知。想让持仓也进入风控，在标的池每行点「标记持有」。

> 想立即试一次：在「盯盘总览」点"立即扫描"，或在「全市场机会」点"立即扫描 / 扫描并推送"。

### 常见邮箱 SMTP

| 邮箱 | 服务器 | 端口 | 说明 |
|---|---|---|---|
| QQ 邮箱 | smtp.qq.com | 465 | 需在邮箱设置开启 SMTP，用**授权码**登录 |
| 163 邮箱 | smtp.163.com | 465 | 同上 |
| Gmail | smtp.gmail.com | 587 | 需应用专用密码 |

465 走 SSL，587 走 STARTTLS。发件人显示名支持中文（自动按 RFC 2047 编码），真实发件地址取 SMTP 账号。

## 四、手动启动（可选）

**后端**
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install fastapi 'uvicorn[standard]' akshare pandas pydantic httpx apscheduler
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**前端**
```bash
cd frontend
npm install
npm run dev
```

> 注意：前端正式界面由 `npm run build` 产出到 `dist/`，由 `vite preview` 提供服务。新增页面/路由后必须重新 build 才会上线。

## 六、数据源与扫描说明

- 数据全部来自 **AKShare**（东方财富、腾讯、同花顺、新浪等公开源），系统不内置任何写死的行情数值。
- 日K历史：东方财富优先，被限流时自动降级到腾讯；实时行情东财限流时降级到新浪并按日K补算量比/换手。
- 东方财富接口有 **IP 限流**：系统已实现结果缓存、失败熔断（限流后 2 分钟不重复请求）、主备源切换。
- 定时推送：全市场机会 14:00 / 14:40；昨日涨停简报 10:30 / 14:40；持仓卖出盘中每 5 分钟（交易时段）+ 14:50 尾盘确认。
- 冷却期：同一股票同一信号在冷却期内不重复提醒，可在配置页调整。
- 战法基于技术形态计算，**每日收盘后结果最准确**，盘中为实时近似值。
- 昨日涨停跟进口径：取"涨停基准日"涨停池，观察其在"表现观察日"的走势（今天看昨天；周五看周四涨停→周五表现，周末看周四涨停→周五收盘表现）。

## 七、策略边界（先看这个再调参）

本项目经 2026-06~11 月多轮回测，结论已固化在 **[STRATEGY_BOUNDARY.md](STRATEGY_BOUNDARY.md)**。核心：

- **正期望**：洗盘反包 + 情绪点火闸门（64.5% / +5.36%）、阶梯仓位、卖出纪律、第5通道回踩MA10、鬼手抄底/减仓。
- **已证伪，勿重复接入**：个股动量 / 新高突破 / 追高、弱转强、低吸、箱体突破、A杀过滤、板块动量闸门；"放宽卖出抓妖股"经 50+ 套方案验证无效。
- 详细逐笔数据与图表见 `reports/`；回测脚本口径见 `backend/backtests/README.md`。

调参前先读该文档，避免重复回测已被证伪的形态。

## 八、注意事项

1. **本地工具**：无需登录，启动即用。
2. **配置安全**：邮箱授权码以明文保存在 `backend/data/config.json`，请勿提交到公开仓库。
3. **接口限流**：标的池建议控制在 10~30 只，全市场扫描一次约 90 秒，过多并发会增大被限流概率。
4. **前端模板**：基于 [Art Design Pro](https://github.com/Daymychen/art-design-pro)（MIT 协议）。
5. **休市数据**：周末/节假日打开时，页面展示的是最近一个交易日的收盘数据，并会标注对应日期。
